# Conversion Performance Analysis

## When to use this skill
Understand how effectively leads move through the full sales journey. Use when the team needs stage-wise conversion data, drop-off analysis, and insight into which stages have the highest business impact if improved.

## What to analyze
- Stage-wise conversion rates and drop-off volumes
- Time between stages (velocity)
- Agent-wise conversion performance
- Project-wise conversion performance
- Source-wise conversion performance
- Current period vs previous period comparison

## What to identify
- Strongest-performing funnel stages
- Weakest-performing funnel stages
- The biggest single conversion gap
- Key contributors to conversion gaps (agent, project, source)
- Highest-impact stages for improvement

## Output structure
Stage Performance → Conversion Gap → Contributors → Business Impact → Focus Area

## Example prompt
"Generate a conversion performance report for the selected period, highlighting stage-wise conversion, major drop-offs, and areas with the biggest gaps."
