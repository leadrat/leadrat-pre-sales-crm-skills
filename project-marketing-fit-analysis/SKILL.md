# Project vs Marketing Fit Analysis

## When to use this skill
Understand whether the right marketing sources are generating quality demand for each project. Use when the team needs to align marketing spend with project-specific lead quality and conversion outcomes.

## What to analyze
- Source → Project → Lead quality → Conversion → Booking flow
- Source contribution broken down by project
- Project-wise source performance comparison

## What to identify
- Best-performing sources per project
- Poor-fit sources generating low-quality leads for specific projects
- Projects that are over-dependent on a single source
- High-potential source-project combinations not yet fully exploited

## Output structure
Source Performance → Project Fit → Quality Gap → Opportunity

## Example prompt
"Generate a project vs marketing performance report showing which sources work best for each project."
