# Agent Performance & Productivity Analysis

## When to use this skill
Understand how effectively each agent handles and converts their assigned opportunities. Use when sales management needs to identify top performers, underperformers, and agents requiring coaching.

## What to analyze
- Leads assigned vs leads actually worked per agent
- First response time per agent
- Calls made and connected calls per agent
- Follow-ups completed per agent
- Meetings and site visits arranged per agent
- Bookings and conversion rate per agent
- Revenue generated per agent

## What to identify
- Top-performing agents
- Underperforming agents
- High-effort, low-result agents (effort gap)
- Low-effort, high-opportunity agents (engagement gap)
- Specific coaching areas per agent

## Output structure
Agent Performance → Gap → Reason → Coaching/Improvement Area

## Example prompt
"Generate a team performance & productivity report for the selected period."
